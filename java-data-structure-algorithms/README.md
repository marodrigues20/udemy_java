# Java Data Structures & Algorithms + LEETCODE Exercises

Código deste projeto referente ao curso da Udemy:

**[Java Data Structures & Algorithms + LEETCODE Exercises](https://www.udemy.com/course/data-structures-and-algorithms-java/learn/lecture/29840398?start=0#overview)**

> Lecture: `29840398`

## Sobre

Repositório com as implementações e exercícios acompanhando as aulas do curso.
Cada tópico fica em seu próprio pacote sob `src/uk/co/`.

## Tópicos cobertos

| Tópico | Pacote |
| --- | --- |
| Listas Ligadas (Simples) | `src/uk/co/singly_linkedlist` |
| Listas Ligadas (Duplas) | `src/uk/co/doubly_linkedlist` |
| Pilha (Stack) | `src/uk/co/stack` |
| Fila (Queue) | `src/uk/co/queue` |

| Árvore Binária de Busca | `src/uk/co/binarysearchtree` |

| Grafos | `src/uk/co/graph` |
| Recursão | `src/uk/co/recursion` |
| Programação Dinâmica | `src/uk/co/dynamic_programming` |

## Como executar

Projeto IntelliJ IDEA (Java). Abra a pasta no IntelliJ e rode a classe `Main` /
`MainTest` do pacote que quiser estudar.

Ou via linha de comando:

```bash
cd src
javac uk/co/<pacote>/Main.java
java uk.co.<pacote>.Main
```
